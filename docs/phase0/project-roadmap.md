# Phase 0: Project Roadmap

## Phase 1: Data engineering and exploration
- Load raw CSVs
- Understand schema and data quality
- Handle missing values and duplicates
- Perform business-focused EDA

## Phase 2: Feature engineering
- Engineer debt-to-income and payment reliability features
- Derive credit history and stability scores
- Create features from bureau and previous application data

## Phase 3: Data pipeline
- Build preprocessing pipeline
- Encode categorical variables
- Scale numeric features
- Create train/validation/test splits

## Phase 4: Model development
- Train logistic regression baseline
- Train random forest
- Train XGBoost or LightGBM
- Compare using business-relevant metrics

## Phase 5: Explainable AI
- Use SHAP for local and global explanations
- Create customer-level risk narratives

## Phase 6: Database design
- Create relational tables for customers, loans, credit history, transactions, predictions, and reports

## Phase 7: Backend API
- Build FastAPI service with prediction and analytics endpoints

## Phase 8: Dashboard
- Build an executive and customer-facing dashboard

## Phase 9: Deployment
- Containerize the service
- Deploy to cloud with environment configuration

## Phase 10: Resume and interview preparation
- Write ATS-friendly bullets and architecture narrative
